# Volta Rápida

Protótipo jogável de um jogo de carros meio idle, meio corrida.

**Jogar:** https://hayatdevbr.github.io/volta-rapida/

| | |
|---|---|
| Setas ou WASD | dirigir |
| Espaço ou ↓ | freio |
| R | reiniciar a corrida |
| Esc | voltar pra garagem |

Um arquivo HTML. WebGL2 puro, sem nenhuma dependência, sem nenhuma textura e
sem nenhum modelo importado — cada triângulo do carro e da pista nasce de um
parâmetro em código.

Em teste. Feedback é bem-vindo.
