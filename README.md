# Volta Rápida

Protótipo jogável de um jogo de carros meio idle, meio corrida.

**Jogar:** https://hayatdevbr.github.io/volta-rapida/

No celular dá para **instalar como app**: abra o link, deite o aparelho e use
"Adicionar à tela inicial".

| | |
|---|---|
| Setas ou WASD | dirigir |
| Espaço | freio de mão — segura pra derrapar |
| Shift | turbo (gasta nitro) |
| E, 1 e 2 | usar item |
| TAB | trocar de item |
| R | reiniciar a corrida |
| Esc | voltar pra garagem |

**Celular:** manche na esquerda, turbo e itens na direita. Deite o aparelho.
**Controle de videogame:** analógico vira, RT/A acelera, LT/B freia, X freio
de mão, RB/Y turbo, LB item.

Três pisos com cara própria — autódromo, rali de terra (com **rampa de
salto**) e circuito urbano na chuva — e um pátio idle onde o carro coleta
energia sozinho, até com a aba fechada.

WebGL2 puro, sem nenhuma dependência, sem nenhuma textura e sem nenhum modelo
importado — cada triângulo do carro e da pista nasce de um parâmetro em
código. O som do motor também: tudo sintetizado.

Em teste. Feedback é bem-vindo.
